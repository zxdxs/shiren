# 識人訓練站 · 家學承傳 · 課孫翁

> 給孩子（孫輩、朋友子侄）用的識人訓練站。
> **不是**教你「看穿別人」，是教你**先別急着下結論**——並且知道自己會看錯。

一個純靜態網站：不用安裝、不用資料庫、不用伺服器、不用 npm。
放上 GitHub Pages 就能用，手機可以「加到主畫面」當 App。

---

## 一、這個站在教什麼

| 目標 | 對孩子意味著什麼 |
|---|---|
| **認識自己** | 我的情緒和身體從哪來？我為什麼今天特別煩？ |
| **理解別人** | 他生氣可能是因為累了、餓了、家裡有事——不是因為他壞。 |
| **保護自己** | 分辨慫恿、分辨讓我身體不舒服的接觸、分辨「大家都在說」的傳聞。 |

**三個硬原則：**

1. **不教任何相術**（面相、手相、骨相一律不碰）。這等於發給孩子一套霸凌工具。
2. **不讓孩子互相判讀**——尤其不評價同學、兄弟姊妹。
3. **觀察對象只限三種**：自己、公開影像、故事人物。

## 二、站的體例：學方法、練技能

本站不是一組模組的集合，而是一條訓練路徑：**知道 → 做到 → 能在沒練過的新情境裡自動做出來**，每一步都有可檢查的證據。

### 分講課件：標重點、理線索、繪圖譜

兩條線：**《人物志》13 講（約 230 分鐘，含附講《冰鑑》）** 與 **《望診遵經》12 講（約 216 分鐘）**，共 **25 講、約 446 分鐘**。

> **附講為什麼存在**：《冰鑑》託名曾國藩，是**相貌決定論**——骨相定貴賤、氣色定吉凶、壽夭、子嗣、刑獄。
> 它不是識人方法，是**反面教材**：本站正文**不引它的判斷內容**，只把它當「觀察如何滑向斷定」的標本。
> 它的命定論述另存於加密區（`assets/vault.js`），通關後才看得到，且附講的警示永遠留在頁面上。

每一講固定六件：

| 件 | 做什麼 |
|---|---|
| **學習目標** | 一句話說清這講要讓你會什麼；並標出對應的四層（L1–L4） |
| **原文・標重點** | 原文照錄，關鍵句以 `[[　]]` 標出並highlight |
| **白話** | 兩三句把原文講通 |
| **圖譜** | 純 SVG 關係圖——`pairs`（配對／對照）、`tree`（一源多流）、`chain`（次第推進） |
| **線索** | 這講在全書脈絡中的位置 ＋ 該書的「全書線索」一句 |
| **練習點** | 直接連到對應的訓練點 |

**圖譜三型**（依原典的結構自動選用）：

- **pairs**——用於配對與對照：五色×五臟×五體、九徵九通道、七繆、相氣十法五對、姿態八法四對
- **tree**——用於「一源多流」：三材→十二流業、材理（四部四家九偏七似…）、八觀、卷下分部
- **chain**——用於「次第推進」：接識（識同體→失異量→互相非駁）、效難二難、釋爭三變、觀察的前提條件

> **線索的例子**：《人物志》全書線索＝
> 九徵立通道 → 體別分流品 → 流業別材任 → 材理辨論難 → 材能論器用 → 利害陳代價 →
> 接識照鏡子 → 英雄分文武 → 八觀給方法 → 七繆除偏誤 → 效難說難處 → 釋爭收束於己。

### 五步與各自的產出物（本站的心臟）

> **訓練不等於閱讀。每一次練習都要求留下產出物——不交產出物＝沒做。**

| 步驟 | 產出物 | 為什麼 |
|---|---|---|
| **① 立基線** | 基線卡（平色：不浮不沉、不清不濁、不微不甚、不散不摶、光明潤澤；主色／客色；老少勞逸校正） | 「望色先知平人」。沒有基線的觀察，等於沒有觀察 |
| **② 只寫看見的** | 觀察記錄（九徵 9 格／色診 6 區／形體 4 項／姿態 8 法＋動作） | 先取得可靠資訊，再談判斷 |
| **③ 判讀** | 十法判讀 ＋ 偏誤自檢（七繆） | 「十法者，辨其色之氣也」 |
| **④ 寫下可證偽的推測** | 推測單（內容＋層級 L2／L3＋信心％＋對帳日＋對帳依據） | 寫不出「什麼能證明它」的句子，不是推測，是抒情 |
| **⑤ 對帳與校準** | 對帳記錄 ＋ 校準報告 | 「辨材須待七年期」——**遷移就發生在回顧這裡** |

### 五層驗收

| 層 | 意思 | 例 |
|---|---|---|
| **L0 記誦** | **能一字不差地背出來** | 名相、條目、口訣——十法、七繆、九徵、八觀、五色配屬，能背才算有 |
| **L1 應知** | 能正確複述並說明 | 不只是背得出，還能說出每一條是什麼意思 |
| **L2 應會** | 標準情境做得出 | 看一段影片能只寫觀察；能填完觀察表與推測單 |
| **L3 深度理解** | 能解釋、能診斷 | 說得出自己錯在哪一繆；解釋得出為什麼 L3 比 L2 難對帳 |
| **L4 遷移** | 新情境自動運用 | 在新場合會自動先立基線、先只寫看見的，不必提醒 |

> **為什麼把記誦放在最前面**：蒙學傳統裡，**背是入口，不是終點**。
> 背不是為了炫耀，是為了【來得及】——看見一個人的當下，你不可能翻書；
> 只有背下來的框架會自己浮出來。所以站上有獨立的 **🗣 記誦** 入口。

### 應記誦：24 條，分類整理 ＋ 逐條解析

按**用途**分成六類（不是按書分，是按「你什麼時候會用到它」分）：

| 類 | 條數 | 內容 |
|---|---|---|
| **一、觀察通道（看哪裡）** | 6 | 九徵、五官候五臟、明堂五區、相氣十法、望色四察、面部二十四部位 |
| **二、配屬（什麼配什麼）** | 5 | 五色配五臟五體、官五色、六經血氣常數、血氣之候（鬚眉）、五音配屬 |
| **三、判準（憑什麼說正常或異常）** | 6 | **平色定義**、五色見生、色以潤澤為本、肥瘦三型、姿態八法、老少十年之變 |
| **四、偏誤（會怎麼看錯）** | 2 | **七繆**、七繆兩句總綱 |
| **五、方法（怎麼做）** | 3 | 八觀、材理七目、識人五步 |
| **六、分品（有哪些類型）** | 2 | 十二偏材、十二流業 |

每一條給你四件：

- **要背的內容**——原文照錄，就是要背下來的東西
- **出處**——哪一本書哪一篇
- **記誦訣**——23 條有口訣（例：明堂五區＝「鼻（明堂）・眉間（闕）・顏（庭）・頰側（蕃）・耳門（蔽）」）
- **解析**——為什麼要背這一條、它怎麼用、以及**該注意的邊界**

> **解析的兩個例子**：
> **平色定義**——「全站最重要的一條。正常就是用十法的兩端都不偏來定義。背下這句，你就有了基線；沒有基線的觀察等於沒有觀察。」
> **十二偏材**——「背法要點：成對背。但本站只把它當『格子』，不當標籤——用途是理解『他偏在哪』，不是『他是哪種人』。」

**記誦狀態**分三檔（未背／在背／會背），存在本機，並計入 **🗂 進度**。
站上還有一個「只顯示未背／在背」的篩選，方便反覆背。

## 三、反饋閉環怎麼運作（長期追蹤）

前面幾個模組都是**一次性**的。要形成閉環，必須**以「人」為單位**長期記錄。長期追蹤模組就是做這件事：

```
① 建立觀察對象（代號，例如「我」「孫A」「公開人物甲」）
        ↓
② 填一次結構化觀察表
   一、只看見的（九徵）：神 精 筋 骨 氣 色 儀 容 言
   二、當下狀態：睡眠 壓力 身體 情緒
   二之二、形體（選填）：面色、頭面、肩背、手足、步態
   二之三、面部色診（尊經）：明堂 闕 庭 蕃 蔽 目
   二之四、肥瘦三型：膕肉 皮 理 身形（純觀察）
   三、五個數字（1–5）：精神 話量 語速 情緒穩定 主動性
   四、我的推測：每條都要寫「層級 L2/L3」「信心 %」「對帳日」
   五、偏誤自檢：這次我可能犯了七繆中的哪幾個
        ↓
③ 到期回來對帳：命中 / 未中 / 無法判定
        ↓
④ 系統算出校準：命中率、平均信心、過度自信、可證偽率、Brier
        ↓
⑤ 下次填表時，表單上方自動顯示「上一次你寫的是……」
   —— 對照著填，你才會看見「他變了沒有、你看準了沒有」
```

**趨勢圖**：五個數字會畫成走勢圖，填過 3 次以上就有意義。

### 兩層的時間尺度不同（最重要的一條設計原則）

| 層 | 觀察什麼 | 預設對帳期限 | 依據 |
|---|---|---|---|
| **L2 狀態** | 睡眠、壓力、身體、情緒 | **7 天** | 幾天到幾週就看得到結果 |
| **L3 心性** | 「他是什麼樣的人」 | **3 年**（快選可到 7 年） | **辨材須待七年期** |

> 白居易《放言五首》其三：
> **試玉要燒三日滿，辨材須待七年期。**
> 周公恐懼流言日，王莽謙恭未篡時。
> 向使當初身便死，一生真偽有誰知？

**為什麼要分開**：短期看，聖人會被流言、篡臣會被讚美——周公被懷疑、王莽被稱頌。
**只有把時間拉長，真偽才顯形。** 若拿「7 天」去對帳心性層，你對帳到的其實是他的狀態，不是他的人。
所以站上把 L3 的預設對帳日設為 **3 年**，並提供「7 天／1 個月／1 年／3 年／7 年」快選；
切換層級時，對帳日會自動跟著調整。

**「七年之約」區塊**會列出所有一年以上的推測，並顯示倒數（還有 N 年 N 個月）。

> ⚠ 這一層的記錄**必須活得比你久**，七年之後檔案還在，閉環才合得上。
> 所以請定期「匯出備份」，並用 `🖨 空白觀察表` 印成紙本。
> **長期追蹤要走好幾年時，紙本比 App 可靠。**

**最重要的一張表是校準表**，它會分開算 **L2（狀態）** 與 **L3（心性）** 的命中率。
正常結果是 L2 明顯高於 L3——這正是這套訓練的設計前提：**練眼力靠 L2，用眼力要對 L3 保持謙卑。**
如果 L3 命中率異常高，先懷疑對帳太寬鬆，或推測寫成了巴納姆語句。

### 觀察對象的三種類型（與倫理界線）

| 類型 | 說明 |
|---|---|
| 🙋 **我自己** | 閉環最快，當天就能對帳。**建議從這裡開始。** |
| 🎬 **公開人物** | 沒有倫理問題，日後有大量公開後續可對帳。適合練心性層，但信心要壓低。 |
| 👨‍👩‍👧 **身邊的人** | ⚠ **只記「狀態」（累、病、壓力、成長），不記「心性評價」。** 這個檔案的目的是校正你自己的眼睛，不是給別人做評估。 |

> **不要讓記錄變成對孩子的監視。** 建議：對身邊的孩子只追蹤「狀態與成長」，
> 把「心性層的長期對帳」留給你自己和公開人物。

## 四、古法體型與可信度分級

《黃帝內經·靈樞》有**兩套並行**的人體分類，原文自己說明了關係：
「五五二十五人，而五態之人不與焉」——它們是互補的。

| 篇 | 內容 | 依據什麼 |
|---|---|---|
| 〈陰陽二十五人〉第六十四 | 五形（木火土金水）× 五 = **25 型** | **形色**：膚色、頭面、肩背、手足、步態 |
| 〈通天〉第七十二 | **五態**：太陰、少陰、太陽、少陽、陰陽和平 | **形狀與舉止**，兼及心性 |

### ⚠ 這條礦脈比相術更危險

因為它披著**《黃帝內經》的權威外衣**——教學者會覺得「這是經典，當然可以教」。
而它裡面混著最硬的命定論述。所以本站沿用**同一套「字形可信度分級」的紀律**，先分級再決定能不能教：

| 級 | 內容 | 處置 |
|---|---|---|
| **A** | 純觀察描述：形色、鬚眉、掌肉、步態 | **可直接教學**——這是本模組真正值錢的部分 |
| **B** | 古人的性格歸納（多憂、少信、好自貴…） | 可作文化材料，**須標明是古人的說法**，不給孩子 |
| **C** | 經脈配屬、五音配屬等理論框架 | 僅供研究，無法驗證 |
| **D** | 命定論述（把壽命、貧富貴賤說成天生註定） | **預設不上站**；另存「原文全本」，需明確確認才顯示，**每次重載自動關回** |

### D 級：用 AES-GCM 加密 —— 放公開 repo 也無妨

**問題**：GitHub Pages 的免費方案只支援公開 repo，D 級內容會變成任何人可讀。
**解法**：**把 D 級內容加密之後才放進 repo。** 托管商、GitHub、任何訪客看到的都是密文。

| 項目 | 值 |
|---|---|
| 金鑰派生 | **PBKDF2-SHA256**，250,000 次 |
| 加密 | **AES-GCM-256** |
| 密文位置 | `assets/vault.js`（8 項） |
| 通關語 | **只在你腦子裡**——不寫進任何檔案 |
| 解密時機 | 在**你的瀏覽器**裡；通關語只留在記憶體，**重新載入即失效** |

> 這也把原先那個「按一下就過」的提示，升級成**真的鎖**：
> 以前任何人都能按確認看到內容；現在沒有通關語，密文就是解不開。

**⚠ 通關語只放在一個地方，而且那個地方不會被上傳**

通關語**不寫在這個 README、也不寫在任何程式檔裡**。它只放在：

```
private/passphrase.txt      ← 已列入 .gitignore，永不進 repo
```

**設定方式**（只需一次）：

```bash
printf '你自己的通關語\n' > private/passphrase.txt
node tools/make-vault.js                    # 自動讀上面的檔案
```

之後 `make-vault.js`、`vault-open.js`、`smoke-test.js` 都會自動讀它，不必每次打。
（也可用環境變數 `SHREN_PASS` 覆蓋。）

建議 **12 字元以上**，不要用字典詞。工具會擋太短的通關語。

> **為什麼不寫在檔案裡**：這個 repo 是公開的。通關語一旦進了 repo，
> 加密就等於沒做——任何人都能拿它解開 `assets/vault.js`。

**之後要修改 D 級內容**（明文已從 `data.js` 清空）：

```bash
node tools/vault-open.js                     # 解密 → private/d-content.json
# 編輯 private/d-content.json
```

### ⚠ 誠實說明：這個加密保護什麼、不保護什麼

| 保護到 | 保護不到 |
|---|---|
| D 級原文不被沒有通關語的人讀到（含 GitHub、托管商、訪客） | 網站其餘內容（本來就是公開古籍，不需保護） |
| 通關語不落地、不進 repo、不進瀏覽器儲存 | **弱通關語**：密文是公開的，任何人可離線暴力破解 → 通關語要夠長、別用字典詞 |
| 重新載入即失效 | 你的觀察記錄（本來就只存在本機 localStorage，從不上傳） |

**這不是「軍事級」防護，而是「讓對方無從審查、也無法隨手翻看」的實用防護。** 對家學工具足夠。

### 真正值錢的是 A 級：兩個純觀察段

**① 肥瘦三型（〈衛氣失常〉第五十九）——本站找到最乾淨的一段**

| 型 | 見於 | 形 | 氣血 |
|---|---|---|---|
| **膏人** | 膕肉不堅，皮緩 | 多氣而皮縱緩，能縱腹垂腴 | 多氣，熱，耐寒 |
| **脂人** | 其肉堅 | 其身收小 | 血清，氣滑少，故不能大 |
| **肉人** | 皮肉不相離 | 身體容大 | 多血則充形，充形則平 |
| **眾人** | 皮肉脂膏不能相加 | 形不小不大，各自稱身 | 常態 |

**全篇無一句人品、無一句命定**——純形體、純觀察。原文的目的也寫得很清楚：
「必先別其三形，血之多少，氣之清濁，而後**調之**。」同篇還有古人的年齡分段
（「五十已上為老，二十已上為壯，十八已上為少，六歲已上為小」）。

> ⚠ 版本註：底本作「人有肥、有膏、有**内**」——「内」為「肉」之訛；下文又別出「脂」，
> 故後世通稱**膏／脂／肉**三型而以「肥」為總稱。站上照原文並標明。

**② 血氣望診（〈陰陽二十五人〉第六十四）**

〈陰陽二十五人〉後半「血氣之候」按經脈分述**鬚、眉、髮、皮、踝、掌肉**的盛衰——這是**純望診的觀察清單**，
講的是「血氣」不是「人品」，完全可觀察、可對照。已整理成 12 條表格。

### 五音配屬（〈五音五味〉第六十五）——C 級，但藏了 A 級

此篇把**五音、五行、五臟、五色、五味、五時、五穀、五畜、五果**一次串起，是《內經》配屬體系的收束處；
並把**二十五型按五音歸成五組**，正好補全〈陰陽二十五人〉的命名。

**但它藏了兩塊 A 級：**
- **鬚眉望診**：「美眉者太陽多血，通髯極鬚者少陽多血，美鬚者陽明多血」——與〈陰陽二十五人〉的血氣候完全呼應。
- **顔色望診**：「黄赤者多熱氣，青白者少熱氣，黑色者多血少氣」。

> ⚠ **版本矛盾（兩篇對不上，本站不硬改）**：〈陰陽二十五人〉木形變體作「**左角**」，
> 此篇角組卻作「**右角**」；宮組此篇底本作「左角宮」，通說作「左宮」。
> **兩處都照原文並標明差異**——這正是需要留痕、不該擅自統一的類型。

> ⚠ 此篇後半論「婦人無鬚」「宦者」「天宦」的生理成因，屬古代生理學說，兼涉性別與生殖，
> **教學時可略，不建議對兒童講**。

### 教學用法（四條）

1. **只取 A 級當觀察詞彙**——把「蒼色、小頭、長面、行安地、舉足浮」加進你和孩子的語彙。
2. **B 級只講「古人這麼說」**——一定要加一句：「這是兩千多年前的人寫的，我們不知道對不對。」這句本身就是最好的批判思維教學。
3. **拿「五態是為了治病」當反例**——原文說「視人五態乃治之」，分類的目的是**幫助**，不是**評價**。正好用來對照：同樣是分類人，目的差別可以有多大。
4. **D 級當成一次教學機會**——不必講內容，只講「這兩篇裡有些話，今天看是錯的，所以我們不用」。讓孩子知道：**經典也會有錯，而且我們要能說出為什麼。**

## 五、望診遵經（以一本書為骨架）

> **更正記錄**：我原本把「望診尊經」當成一句方法論口號，於是從《內經》各篇摘錄拼出一個模組。
> 這是錯的——**它是一本書**，而且正確書名是《望診**遵**經》。書名本身就是它的論點：
> **「治病必須知診。診病必須遵經。」**

| | |
|---|---|
| **書名** | 《望診遵經》 |
| **作者** | 清·汪宏（新安人） |
| **年代** | 光緒元年（1875） |
| **規模** | 二卷，**101 篇** |
| **地位** | 把《內經》散在各篇的望診，第一次系統化為專著 |

**為什麼這件事重要**：我原本的模組是「摘錄《內經》」；汪宏的書是「把《內經》系統化」。
兩者層級不同。**《內經》是根，這本書才是骨架**——它已經替你把望診分好了類。

### 書的結構（101 篇）

- **卷上**：總論 · 氣色十法 · 分參（老少／氣質／居養／四時／五方）· 五色主病條目
- **卷下**：**按部位**——目（5篇）、舌（5篇）、口、唇、四白、牙齒、鼻、耳、眉、髭鬚、髮、頭、面、
  腹、背、手、足、毫毛、腠理、尺膚、皮、肉、絡脈、筋、骨、爪甲、乳、臍、汗、血、痰、二便、月經；
  **按姿態**——形體周身部位、身形、身容、形容大綱、**行止動靜、診坐、診臥、身容四法、意態**

站上收錄完整篇目，當作一張「還有什麼可看」的地圖。

### 核心：相氣十法

《內經·五色》只給了四個提示（浮沉、澤夭、散摶、上下）。**汪宏把它擴成十法，各配一組判斷**：

| 法 | 定義（原文） | 分什麼 |
|---|---|---|
| **浮沉** | 色顯於皮膚間者謂之浮；隱於皮膚內者謂之沉 | **分表裡** |
| **清濁** | 清者清明，其色舒也；濁者濁暗，其色慘也 | **分陰陽** |
| **微甚** | 色淺淡者謂之微；色深濃者謂之甚 | **分虛實** |
| **散摶** | 散者疏離，其色開也；摶者壅滯，其色閉也 | **分久近** |
| **澤夭** | 氣色滋潤謂之澤；氣色枯槁謂之夭 | **分成敗** |

> 十法者，辨其色之氣也；五色者，辨其氣之色也。氣者色之變，色者氣之常。

**這是全書最見功夫的地方**，也是本站望診現在的骨架。比「青赤黃白黑」高一個層次。

### 這兩篇改寫了我的設計

**① 〈望色先知平人〉——本站原本的設計缺陷**

> **凡欲知病色，必先知平色。**
> 平人之色：不浮不沉，不清不濁，不微不甚，不散不摶，**光明潤澤**，血華其色也。

請注意這句話的結構：**汪宏用剛好那十法來定義「正常」——正常就是兩端都不偏。**

⚠️ **我的觀察表原本只叫人記錄顏色，卻沒有先建立「平色基線」。這是缺陷。**
正確順序是：先記錄這個人不偏不倚、光明潤澤的樣子，之後每一次記錄都是**相對基線的偏離**。

**② 〈色以潤澤為本〉——一句話抵一整章**

> 靈素論脈，以胃氣為本；**望色，以潤澤為本。**
> 脈之胃氣，脈之神也；色之潤澤，色之神也。
> 光明潤澤者，氣也；青赤黃白黑者，色也。**有氣不患無色，有色不可無氣也。**

**真正該看的不是「什麼顏色」，是「有沒有光」。** 這也解釋了《內經》為何說「審察澤夭，謂之良工」。
且此章有五句可觀察的比喻（**青如翠羽、赤如雞冠、黃如蟹腹、白如豕膏、黑如烏羽**）——教孩子看這個，比背五色配五臟有用得多。

### 分參：汪宏比《內經》好用之處

| 篇 | 給你的東西 |
|---|---|
| **老少望法相參** | 一份古人給的年齡觀察表：**十歲好走、二十好趨、三十好步、四十好坐、六十好臥**——全是可觀察的行為。並提醒「有年已老而體未衰者，有年方壯而形先槁者」，不可硬套年紀 |
| **氣質望法相參** | **主色**（隨五形發見，百歲不變）vs **客色**（四時加臨，推遷不常）。這正是本站「體質 vs 狀態」的古人說法，而且更精準 |
| **意態望法提綱** | 一個我完全沒有的維度：觀察一個人**想要什麼**——想不想見人、喜明喜暗、愛暖愛涼、衣多衣少。全部可觀察，且不必碰他的品格 |

### 姿態：汪宏用了八篇，本站原本完全沒有

這是「從其用反推」的結果。

**這張表的「用」是什麼？是對帳**——記下觀察，數天到數週後驗證。
所以取捨標準不是「古書寫了什麼」，而是**「這一項會不會變、能不能對帳」**：

| 層 | 內容 | 去向 |
|---|---|---|
| **會變的姿態** | 疲勞、不適、疼痛、情緒造成的姿態 | ✅ **收進觀察表**（數天可對帳） |
| **終身稟賦** | 如「少陽之人立則好仰、行則好搖」 | ❌ 歸**基線**，不是狀態 |
| **醫療診斷** | 「坐而仰＝肺實」「多睡＝脾虛」 | ⚠ 標明**不可自行診斷** |

**汪宏的八法本身就是「兩端」結構**，正好接上先前的平色基線設計：

| 對 | 陽端 | 陰端 |
|---|---|---|
| **動靜** | 動 | 靜 |
| **強弱** | 強 | 弱 |
| **俯仰** | 仰 | 俯 |
| **屈伸** | 伸 | 屈 |

> **得其中，則之八者皆不可言病；不得其中，則之八者皆可言病。然而中無定體。**

又一次是基線邏輯——**正常＝不偏兩端**。而且汪宏補了**校正因子**：

> 寒則多屈，熱則多伸；陰則多俯，陽則多仰；勞則多強，逸則多弱；少則多動，老則多靜。

**判讀前必須先把這八項扣掉**——冷了會屈、老了會靜，那不是病。

**收進觀察表的具體動作**（每一項都附「可以這樣猜，然後對帳」）：

| 類 | 項數 | 例 |
|---|---|---|
| **坐** | 8 | 坐而伏 → 猜「氣不足、很累」；以手護腹 → 猜「腹部不適」 |
| **臥** | 10 | 但欲寐 → 猜「精神很差」；伏睡 → 猜「腹部不適」 |
| **身容** | 4 | 項背強 → 猜「頸背僵硬」；心戰 → 猜「內在虛寒」 |
| **行** | 2 | 行遲 → 猜「陽不足、沒力」 |

D 級另收三條死候性質的判斷（形體不仁、翻身不能、腰脊不可俯仰），**同樣加密**。

### ⚠ 舌診的結論也修正了

原本我寫「舌診其實不尊經」——**這對《內經》是對的，但要修正**：
《望診遵經》卷下收了**五篇**舌診（望舌診法提綱、診舌形容條目、診舌氣色條目、診舌苔垢條目、診舌津液條目）。

**舌診不入《內經》，卻入了《望診遵經》**——因為汪宏這本書的範圍比《內經》寬。
所以：**舌頭日記有正當性，依據是《望診遵經》而不是《內經》。** 站上仍標明這層來歷；
而且此書給的骨架比「舌質／舌苔」兩分更細（形容、氣色、苔垢、津液四路），值得日後照它細分。

> 你若當著他的面說「那人面相不好」，前面五課全部作廢。

> **永遠留一句「也可能是我看錯了」。** 這句要成為口頭禪。
> 孩子學到這句話，這門課就成功了。

> **不要教成考試。** 孩子若覺得這是功課，就會開始應付你——
> 而且他會學會「說你想聽的話」，那正好是識人的反面。
